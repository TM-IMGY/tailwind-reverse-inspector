Privacy Policy — Tailwind Reverse Inspector

Effective date: 2026-11-03

Tailwind Reverse Inspector is a browser extension that reads the computed CSS styles of an element you click on the current page and converts them into Tailwind CSS utility classes.

What this extension does

  • All style inspection and class generation happens entirely locally, in your browser. No page content, URL, HTML, or CSS is ever sent to any server.
  • The extension does not collect, store, or transmit any browsing data, page content, or personal information.
  • The extension only runs on a page when you explicitly click the extension's toolbar icon (it does not run automatically in the background on every page you visit).

Payments

  • Paid ("Pro") upgrades are processed by a third-party payment provider, ExtensionPay, which uses Stripe to process payments. Payment and billing information is handled entirely by ExtensionPay/Stripe and is never seen by this extension or its developer beyond whether your account is marked as paid.
  • See ExtensionPay's own privacy policy for details on data handled during checkout.

Data storage

The extension uses Chrome's local/sync storage only to remember your license (paid/unpaid) status. No other data is stored.

Contact

Questions about this policy can be sent via the "Contact Provider" / support link on this extension's Chrome Web Store listing, or by opening an issue on the GitHub repository.
